# Data-Modeling-in-Power-Bi-Project

Hi friends👋, welcome to this page!<br>
Data preparation in Power BI consists of two foundational phases, data transformation and data modeling.
Once raw datasets are cleaned and structured in Power Query, establishing proper dimensional modeling becomes essential.
This is because a well-architected data model could minimize query load times, reduces the complexity of DAX measures, and on top of all that, it would make easier when visualizing report.
